## Core proposal preserved from v0.3

The note does not claim that the empty-slot device itself is novel. It proposes a causal 2 × 2 factorial dissociation of two candidate factors:

- **Spatial fixedness:** fixed versus mobile location.
- **Operational reversibility:** unidirectional versus bidirectional operation.

The four cells are F-U, F-R, M-U, and M-R. The primary confirmatory estimand is the spatial-fixedness-by-reversibility interaction. The primary outcome is the child’s first unprompted response in a novel ordering task using empty, 1, 2, and 3 states, with correct performance defined as placing the empty state immediately before 1.

Version 0.3 balances starts at 0 and 3 across conditions to reduce confounding of reversibility with starting or ending state. It proposes logistic regression for the binary primary outcome, preregistration of a smallest effect size of interest, simulation-based sample-size determination, and a distinction between a precise null result and an underpowered unresolved result.

## Staged distinctions in v0.3

The document contains two related sets of distinctions that require clearer provenance and alignment in a future revision.

Early in the note it distinguishes:

- Absence
- Return state
- Zero objects
- Symbol 0
- Operational zero
- Spatial origin

Later it presents a five-stage model:

1. Empty place
2. Absence
3. Return
4. Zero objects
5. Abstraction

This presentation was one of the places where the external reader could not determine clearly enough what was established background, what was adapted from prior work, and what was newly proposed.

## Definition issue highlighted by expert feedback

The research question introduced “spatial fixedness” as “re-identifying the same empty state in the same place.” Later sections gave a more concrete operational description: a fixed slot is a designated place that remains identifiable when empty. Future revision should move the concrete operational description before the theoretical label is relied upon.
