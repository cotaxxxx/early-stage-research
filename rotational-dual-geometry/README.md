## Scope

This is a synthesis / research-program note connecting planar dual phase to higher-dimensional rotational dual geometry. It does not present itself as a standalone new-results paper. Instead, it organizes classical polar-duality facts, effective dual phase, local dual phase, dual-phase spectra, and higher-dimensional optimal rotations into one framework.

## Core framework

The central relation is

`K° = c Q K`, with `Q ∈ SO(d)` and `c > 0`.

The manuscript explicitly distinguishes two different defect functionals that share the same exact zero set but generally differ away from zero:

- a support-function linear L2 defect;
- a scale-invariant logarithmic-variance defect.

## Companion results

The note states that the technically proved companion results belong to the logarithmic-variance defect:

- the fully solvable rectangle-family bifurcation model;
- the three-dimensional cube degree-four mode theorem and the remaining higher-harmonic certification problem.
